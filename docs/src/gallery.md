# Gallery

AlgebraOfVega ships a gallery of examples — AlgebraOfGraphics specs
translated to Vega-Lite, rendered live in your browser. Each plot's
title links to a standalone page; dropdown / brush / zoom controls
inside individual plots work right here in the docs.

```@raw html
<div class="htmxo-embed" data-hx-base="live-aov/" hx-trigger="load" hx-swap="innerHTML">
  <em>Loading AoV gallery…</em>
</div>
```
