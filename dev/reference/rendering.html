AlgebraOfVega.to_vegalite Function
julia
to_vegalite(spec; interactive=true, auto_remap=nothing) -> Dict{String,Any}

Convert an AoG Layer, Layers, or VegaSpec to a Vega-Lite JSON dictionary. Handles all translation: mark types, encodings, statistical transforms, config merging, and, by default, auto-interactivity. Set interactive=false to suppress only the parameters generated automatically by AoV; explicit config(params=...) and config(select=...) remain in the output.

For a plot rendered through the channel picker, pass the picker's keywords as auto_remap — the same (; dims, fixed, pinned, off, …) given to auto_remap_node, with_plot_caption(...; auto_remap=…) or update_spec. The result is the Vega-Lite that picker embeds before the reader changes anything (resolved channels, combined facet columns, broadcast facet fields), without building the picker controls or a plot node — e.g. for a JSON, markdown or static export of that figure. An already-lowered Vega-Lite Dict cannot be remapped: it no longer carries the layer tables.

source
julia
to_vegalite(spec, scales; interactive=true, auto_remap=nothing) -> Dict{String,Any}

Mirror of AlgebraOfGraphics.draw(spec, scales(...)): lower spec (a Layer, Layers, or VegaSpec) to a Vega-Lite dict, then apply the AoG Scales override to it. This is the second-positional-argument form; config(scales=scales(...)) applies the identical override inline.

Handles X/Y/Z axis scales (log/log2/log10/sqrt/symlog + nice/zero/domain/ clamp/constant) and a categorical/continuous Color scale — palette (explicit colours or a named scheme), categories (domain/group ORDER), colormap (named scheme), colorrange (continuous value range; values outside it take the colormap's end colours, or lowclip/highclip), scale (log/sqrt/symlog) and nan_color. Any other AlgebraOfGraphics colour attribute warns that it is not lowered, and a key AoG rejects (including clamp) is an ArgumentError. The Color override is merged only into color= and strokecolor= encodings that carry a field, so a layer with a deliberate field-less colour (e.g. a pointinterval() median dot) is never given a bare, VL-dropped colour encoding. Each key reaches only colour encodings of its kind: categories/palette the nominal/ordinal ones, the continuous keys the quantitative/temporal ones, so one override configures both colours of a figure that mixes them. A key no colour encoding of the figure can take is an ArgumentError, as in AoG.

AlgebraOfVega.vsave Function
julia
vsave(spec, path; locale=nothing, scale=nothing, ppi=nothing, auto_remap=nothing) -> path
vsave(spec, scales(...), path; kwargs...) -> path

Save the Vega-rendered figure to PDF, SVG, or PNG and return path. Requires the vl-convert command-line executable on PATH, or at the path in AOV_VL_CONVERT. Supports AoV geographic and interval analyses.

AlgebraOfVega.sdraw Function
julia
sdraw(spec, path::AbstractString; kwargs...)

Render an AoG spec via AlgebraOfGraphics.draw → Makie → file. Saves the figure to path (format inferred from extension) and returns an h.img node pointing to path.

alt gives the image its alt text, a description of what the figure shows (<img src alt>, Markdown carrying the alt). An accessible (PDF/UA) report needs it on every figure; without alt the image has none.

AlgebraOfVega.sdraw! Function
julia
sdraw!(position, spec)

Render an AoV spec into an existing Makie figure, layout position, or axis via AlgebraOfGraphics.draw!. This is the static composition counterpart to sdraw_file: create a Figure, place independently configured specs with sdraw!(fig[row, col], spec), then save the complete figure with Makie.save.

Each spec keeps its own config(axis=...), config(facet=...), and config(scales=...) settings. config(width=...) and config(height=...) are standalone-figure settings and are therefore ignored when drawing into an existing layout. mapping display labels (:x => "Label"), including lineribbon/ribbon(bands=...) x/y/colour/facet labels, are preserved on the rebuilt static layers.

Like AlgebraOfGraphics.draw!, this does not add legends or colorbars — call AlgebraOfGraphics.legend!(position, grid) with the returned grid afterwards (see aov-use §1a for the composition pattern).

Requires a Makie backend (e.g. CairoMakie) to be loaded. Returns the result of AlgebraOfGraphics.draw!.

AlgebraOfVega.vega_head Function
julia
vega_head(; vega_version, vegalite_version, vega_embed_version, source, base, runtime, zoom, max_width, actions, theme)

Return HTML head nodes for the plotting libraries and AoV browser runtime. Include them once in a host page. source=:cdn uses pinned URLs and integrity hashes; :vendor loads from base; :inline embeds the vendored bytes. runtime=:linked requires source=:vendor and links the runtime and stylesheet.

The default theme=:host follows the plot element's inherited foreground and font. theme=:none keeps Vega's own appearance. zoom, max_width, and actions set page defaults. Author-specified mark palettes remain unchanged when the host theme switches.

CSS properties on the plot or an ancestor can set the host appearance:

PropertyMeaning
--aov-fontFont-family list.
--aov-categoryDefault categorical colors, separated by commas.
--aov-axis-label-color, --aov-axis-title-colorAxis text colors.
--aov-grid-color, --aov-tick-color, --aov-domain-colorGrid, ticks, and axis lines; none removes them.
--aov-view-colorPlot frame color; none removes it.
--aov-legend-label-color, --aov-legend-title-colorLegend text colors.
--aov-header-label-color, --aov-header-title-colorFacet header colors.

These defaults leave explicit mark colors and scale palettes intact. Class, data-theme, or style changes on the document root or body refresh the plots. After other stylesheet changes, call AoV.refreshTheme() in the browser.

Channel controls ​

AlgebraOfVega.auto_remap_node Function
julia
auto_remap_node(plot_id, spec; dims, fixed=Dict(), pinned=:row, axes=false, texts=plot_texts())

Render a figure with controls that assign dimensions to color, row, column, and detail channels. dims is a vector of field => label pairs. fixed maps channels to fields that cannot be reassigned by the reader; pinned selects the channel that retains dimensions otherwise unassigned. axes enables axis remapping for marks whose axes are not bound to computed analysis columns. texts controls UI labels.

Use a stable plot_id. When updating or exporting the figure, pass the same remapping options as auto_remap to update_spec, to_vegalite, or to_json. The browser retains the reader's assignment during a supported data refresh.

AlgebraOfVega.cell_charts Function
julia
cell_charts(spec[, scales]; texts=table_texts(), sigdigits=3, id=nothing,
            total=nothing, label=nothing, text=nothing) -> CellCharts

Build a column of small charts from a specification faceted by the table's row key through layout. Index the result with cells[key] to obtain the row's HTML table cell. Cells share scales unless the figure unlinks an axis. Requires using HTMXObjects and a host page with vega_head().

AlgebraOfVega.PlotTexts Type
julia
PlotTexts

The words AoV's own plot chrome shows: the caption's "More" toggle, the caption row's download menu and buttons and its Share button, the "Show data" preview and its summary table, the channel picker's labels, a frame player's play/pause button (config(frame=…)), a coloured ribbon's "Ribbons | Intervals" switch (lineribbon(...; intervals=…)), the accessible name of a plot or data table that scrolls in its frame, and standalone HTML exports. Build one with plot_texts and pass it as texts= to with_plot_caption, to_html, auto_remap_node, mapping_controls, caption_share_button, with_caption_share or summary_share_button.

A text in braces is a placeholder AoV fills in: image takes {format} (PNG, SVG); interval takes {point} (the median text) and {width} (95%); overlap takes {score} (34%), and overlap_auto takes {score} and {threshold} (10%).

caption_action_inject(rv, action_js) -> Node

Post-hoc caption-action injector: wraps the already-rendered rv in an h.div plus a self-removing <script> that finds (or creates) the .caption-actions span inside the enclosing figure.captioned and runs action_js with it bound as acts.
