Configuration ​

AlgebraOfVega.config Function
julia
config(; kwargs...)

Attach Vega-Lite configuration to a drawable with spec * config(...). Use width, height, and title for the figure; axis=(; ...) for labels and limits; and scales=scales(...) for scale configuration using AlgebraOfGraphics names. The same scales(...) object can be the second argument to vdraw or to_vegalite.

params, transform, and other Vega-Lite properties provide an escape hatch. select adds filter controls; frame selects an animation coordinate; link connects hover identity across figures. Per-layer configuration stays with its layer. Configuration applied to a combined figure applies to the combined result.

Use a configured drawable with vdraw for a browser or sdraw for Makie. Browser-only settings need not have a static-rendering equivalent.

AlgebraOfVega.symlog Function
julia
symlog

Scale marker for an axis that is linear near zero and logarithmic farther away. Pass as scale=symlog in an X or Y scale configuration. Unlike a logarithmic axis, it can represent genuine zero values.

The optional constant sets the Vega-Lite linear region's half-width. The Makie path uses Makie.pseudolog10 with its fixed unit region, so changing constant affects the browser path only.

AlgebraOfVega.locale_config Function
julia
locale_config(lang::Symbol=:en) -> Config

Number and time locale for Vega plots: :de selects d3's German (de-DE) definitions, :en selects US English (en-US, Vega's default). Unknown names throw ArgumentError. The definitions are bundled; no download is needed.

Multiply it with a plot or another config, for example spec * locale_config(:de) * config(config=(; legend=(; orient="top"))). It sets config.locale.number and config.locale.time, leaving axis, legend, and format choices to the plot. :en explicitly restores English when composed after :de. Each call owns its data, so editing one config affects no other.

The locale supplies decimal/group separators, currency, day/month names and the %x/%X/%c time formats. For a particular date or tick layout, compose config(config=(; timeFormat="%d.%m.%Y", axisTemporal=(; format="%d.%m.%Y"))). Caption and control labels use plot_texts separately. This is a Vega setting (vdraw, to_vegalite, vsave); Makie's sdraw ignores it.
