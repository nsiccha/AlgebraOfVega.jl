Algebra and mappings ​

AlgebraOfVega provides these names itself, with AlgebraOfGraphics' spelling and meaning, so the browser path loads neither AlgebraOfGraphics nor Makie.

NamesTask
data, vdataAttach a Tables.jl source; vdata avoids a local name collision.
mapping, visual, dimsMap columns, set mark attributes, or map array dimensions.
renamer, sorter, nonnumeric, verbatim, presorted, directLabel, order, or classify mapping values.
scale, scales, pregrouped, wrappedIdentify scales, configure them, supply grouped data, or wrap facets.

The composition guide demonstrates the algebra. The scale guide shows the supported scale-configuration path.

AlgebraOfVega.data Function
julia
data(table)

Create a Layer with its data set to a Tables.jl-compatible table; multiply with mapping to select its columns. data(Pregrouped()) marks pregrouped input (see pregrouped).

AlgebraOfVega.mapping Function
julia
mapping(positional...; named...)

Create a Layer with positional and named column selectors. A selector is a column name or index, optionally paired with modifiers and a label: :x => "X label", :g => sorter("b", "a") => "Group", :k => nonnumeric, direct(values), dims(1).

visual(plottype=Plot{:plot}; attributes...)

Create a Layer that draws with plottype (Scatter, Lines, Band, …; see AlgebraOfVega.PlotTypes) and the given visual attributes.

Marks ​

NamesGraphic
Scatter, Lines, ScatterLines, StairsPoints and ordered trajectories.
BarPlot, HeatmapBars and rectangular cells.
BoxPlot, Violin, RainClouds, Hist, ECDFPlotDistribution displays.
Band, Errorbars, Rangebars, CrossBarBounds and intervals supplied as coordinates.
HLines, VLines, HSpan, VSpanReference rules and shaded ranges.
ContourContours.

These are AlgebraOfVega's plot-type names (AlgebraOfVega.PlotTypes), spelled like Makie's plot types and used as arguments to visual; browser rendering loads no Makie. With Makie loaded, visual also accepts Makie's own plot types, such as Makie.Text. See coordinates for positional-mapping exceptions.

AlgebraOfVega.PlotTypes Module
julia
AlgebraOfVega.PlotTypes

The plot-type vocabulary named in visual(...): Scatter, Lines, Band, BarPlot, … (plus the unexported Text and Density). Each name is a Plot{f} token, where f is the name of the Makie plotting function of the same plot type (Scatter === Plot{:scatter}). The Vega-Lite path maps a token to a mark; the static path (Makie extension) maps it to the Makie plot type of the same name, and visual also accepts Makie's own plot types once Makie is loaded.

AlgebraOfVega.Makie is a compatibility alias of this module, so the spelling visual(AlgebraOfVega.Makie.Text) keeps working; it is not the Makie package.

Stacked panels ​

AlgebraOfVega.vconcat Function
julia
vconcat(panels...; spacing=8, linkxaxes=:all) -> VConcat

Stack figures top to bottom on one shared x scale, as one plot: a main panel with a bar panel under it, such as a forecast over the hourly precipitation. Each panel is an ordinary figure (data(...) * mapping(...) * visual(...), with its own config(height=…), scales and legends); they share the x scale, so their plot areas line up exactly, the x axis is labelled once under the bottom panel, and the readout (§11g) and an x zoom run across all panels. spacing is the gap between the panels' plot areas in pixels.

Use it wherever a figure goes: vdraw, to_node, with_plot_caption, vsave, to_vegalite.

linkxaxes=:none (AlgebraOfGraphics' name, as in config(facet=(; linkxaxes=:none))) stacks panels that each keep their own x scale instead: every panel draws its own x axis and pans and zooms on its own, and the readout follows the panel under the pointer. Use it for panels in different units, such as a forest of parameters near 400 ms above one of coefficients near 0. The colour legend and its selection stay one for the stack.

A panel cannot be faceted, a frame animation or a cell column, and the channel picker works on one figure only (ArgumentError). The panels share one link group (config(link=…)) if any has one. A ribbon panel draws the drawing it starts in, without the Ribbons | Intervals switch. sdraw composes Makie panels with sdraw! and Makie.linkxaxes! instead.

Configuration ​

AlgebraOfVega.config Function
julia
config(; kwargs...)

Attach Vega-Lite configuration to a drawable with spec * config(...). Use width, height, and title for the figure; axis=(; ...) for labels and limits; and scales=scales(...) for scale configuration using AlgebraOfGraphics names. The same scales(...) object can be the second argument to vdraw or to_vegalite.

params, transform, and other Vega-Lite properties provide an escape hatch. select adds filter controls; frame selects an animation coordinate; link connects hover identity across figures; legend_zoom=true makes a colour legend selection also zoom each panel's axes to the selected entries' marks. Per-layer configuration stays with its layer. Configuration applied to a combined figure applies to the combined result.

Use a configured drawable with vdraw for a browser or sdraw for Makie. Browser-only settings need not have a static-rendering equivalent.

AlgebraOfVega.symlog Constant
julia
symlog

Scale marker for an axis that is linear near zero and logarithmic farther away. Pass as scale=symlog in an X or Y scale configuration. Unlike a logarithmic axis, it can represent genuine zero values.

The optional constant sets the Vega-Lite linear region's half-width. The Makie path (the AlgebraOfVegaMakieExt extension) draws Makie.pseudolog10 with its fixed unit region, so changing constant affects the browser path only. As a function, symlog(x) = sign(x) * log10(abs(x) + 1), the forward map of Makie.pseudolog10; with Makie loaded, scale=Makie.pseudolog10 is read as symlog.

AlgebraOfVega.locale_config Function
julia
locale_config(lang::Symbol=:en) -> Config

Number and time locale for Vega plots: :de selects d3's German (de-DE) definitions, :en selects US English (en-US, Vega's default). Unknown names throw ArgumentError. The definitions are bundled; no download is needed.

Multiply it with a plot or another config, for example spec * locale_config(:de) * config(config=(; legend=(; orient="top"))). It sets config.locale.number and config.locale.time, leaving axis, legend, and format choices to the plot. :en explicitly restores English when composed after :de. Each call owns its data, so editing one config affects no other.

The locale supplies decimal/group separators, currency, day/month names and the %x/%X/%c time formats. For a particular date or tick layout, compose config(config=(; timeFormat="%d.%m.%Y", axisTemporal=(; format="%d.%m.%Y"))). Caption and control labels use plot_texts separately. This is a Vega setting (vdraw, to_vegalite, vsave); Makie's sdraw ignores it.
