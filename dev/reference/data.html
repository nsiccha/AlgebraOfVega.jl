AlgebraOfVega.by_url Function
julia
by_url(rows, url)

Attach a browser data URL to a Tables.jl source. Julia retains access to the rows for mappings and analyses; a raw-row browser figure can load them from url instead of embedding another copy. Serve rows_json(rows) at that URL.

Analyses that calculate new summaries in Julia still need to transmit their computed result. A URL must be reachable from the final page, including any site or reverse-proxy prefix.

source
AlgebraOfVega.rows_json Function
julia
rows_json(rows) -> String

Serialize a Tables.jl source as the JSON rows expected by by_url. Use the returned string as the response body at the figure's data URL.

AlgebraOfVega.preaggregate Function
julia
preaggregate(table; y=:y, group_keys=Symbol[], probs=[0.025, 0.10, 0.25, 0.5, 0.75, 0.90, 0.975])

Group table by group_keys and compute the specified quantiles of y. Return a named tuple of columns containing the group keys and quantiles. The median column is median; other quantile columns use names such as q025, q25, and q975. These columns can be passed to interval analyses through their bands argument.

Sample data ​

The small sample_cars, sample_tips, and penguin explorer fixtures are adapted from public teaching datasets: Vega cars, seaborn tips, and Vega penguins. They are plotting fixtures; use the original datasets for scientific analyses. The stock prices, city temperatures, population and sales counts, posterior draws, and regression predictions are synthetic teaching values. They do not report market prices, weather records, census counts, business results, or fitted research models.

AlgebraOfVega.explorer_widget Function
julia
explorer_widget(datasets_or_table; kwargs...)

Return an HTMX Node for the explorer widget (for web apps using HTMXObjects).

Accepts either a Dict{String => table} of named datasets or a bare table (auto-wrapped as Dict("data" => table) with the dataset dropdown hidden).

Includes dropdowns for: dataset, x, y, color, group (detail encoding), facet column, facet row, and mark type, plus checkboxes for independent X/Y axes and log X/Y scale. When mark is "line+ribbon", a "Ribbon levels" text input appears for tuning quantile bands.

Keyword arguments

  • default_ds: which dataset to pre-select (auto-falls back to first available key)

  • title: heading text, or nothing to hide (default: nothing)

  • subtitle: description text, or nothing to hide (default: nothing)

  • default_x, default_y: pre-select x/y columns (default: nothing = first/second column)

  • default_color, default_group, default_col, default_row: pre-select categorical dropdowns (default: nothing = "(none)")

  • default_mark: pre-select mark type (default: "point")

  • default_indep_x, default_indep_y: pre-check independent axis checkboxes (default: false)

  • default_log_x, default_log_y: pre-check log scale checkboxes (default: false)

  • width: plot width for non-faceted specs — integer or "container" (default: "container")

  • height: plot height for non-faceted specs (default: 350)

  • default_filter_include: initial filter pill selection for categorical columns. Accepts three forms: a Dict of lists (Dict("col" => ["val1", "val2"])) to select specific values, a Dict of functions (Dict("col" => v -> v != "x")) to select values matching a predicate, or a global callback (col, val) -> Bool applied to every categorical column. Default: nothing (all values selected).

  • marks: list of value => label pairs for the mark dropdown (default: _default_marks())

  • show_spec: whether to show the Vega-Lite JSON spec details section (default: false)

  • defaults: optional NamedTuple (; x, y, color, row, col, group, mark, filter) of column names / mark values used to emit an inline init <script> that pre-populates the dropdowns and calls AoV.explorerUpdate() after a 100ms setTimeout. Empty when missing — no script emitted. Use this when the available columns are only known at the call site (e.g. dynamic upstream tables); for column-known-at-build-time defaults prefer the default_* kwargs.

Faceted specs use responsive cell widths derived from the container's clientWidth rather than a fixed size. See explorer_js for details.
