Intervals ​

AlgebraOfVega.pointinterval Function
julia
pointinterval(; probs=[0.95, 0.8, 0.5], point=:median, orientation=:horizontal)
pointinterval(; bands=[:q025 => :q975, :q25 => :q75], orientation=:horizontal)

Draw nested empirical intervals and a central point. With probs, summarize raw values using quantiles in Julia. With bands, read precomputed lower/upper column pairs, widest first; the first positional mapping is the center column.

The default horizontal orientation maps values to x and categories through y. Vertical orientation requires positional mappings (category, value). Color groups at the same category are dodged automatically; dodge_y or dodge_x selects the dodge field explicitly. detail preserves extra grouping columns. A fixed visual(; color=...) colors interval rules; color=:ink follows the page foreground. Other visual attributes are not applied.

Intervals describe the supplied distribution. They are credible intervals only when that distribution consists of appropriate posterior draws.

AlgebraOfVega.lineribbon Function
julia
lineribbon(; probs=[0.95, 0.8, 0.5])
lineribbon(; bands=[:q025 => :q975, :q25 => :q75])

Summarize y at each x with a median line and nested quantile ribbons. Use raw values with probs and a group mapping for draw identity, or precomputed lower/upper column pairs with bands. The two positional mappings are x and the value or median. detail preserves grouping columns. A color mapping identifies separate series; fixed visual(; color=...) colors a series without grouping.

At a single x position, single_x_glyph=true uses an interval glyph. Over at most 12 numeric x values (a dose ladder), coloured or not, the figure can also be drawn as point-intervals, and the intervals option picks the drawing it starts in. Use ribbon_view to inspect that choice before rendering.

AlgebraOfVega.ribbon_view Function
julia
ribbon_view(spec; auto_remap=nothing) -> NamedTuple
ribbon_view(spec, scales(...); auto_remap=nothing) -> NamedTuple

Whether a lineribbon/ribbon figure gets the "Ribbons | Intervals" switch, and which drawing it starts in: the facts the switch's tooltip shows, read from the figure to_vegalite lowers from the same arguments (pass the picker's keywords as auto_remap for a figure drawn through the channel picker). Returns (; offered, why_not, start, score, threshold):

  • offered: whether the figure carries the switch.

  • why_not: nothing when it does; otherwise the condition the figure misses. :no_ribbon (no lineribbon/ribbon layer), :several_ribbons (more than one), :detail (a detail= split), :not_numeric_x (a date or text x), :no_x_values (no rows with an x value yet), :too_many_x (more than 12 distinct x values across the figure) or :x_off_slots (the point-interval drawing puts the x values on evenly spaced slots, and another layer's x cannot sit on one: a value that is not one of the ribbon's x values, or a binned, aggregated or datum x).

  • start: :ribbons or :intervals, the drawing the figure starts in.

  • score: the overlap score the tooltip shows (to three decimals): how far the colour groups' outer bands overlap, as a share of the y range. It is measured whatever intervals= says, so a fixed start can be calibrated too. It is 0.0 when no two colour groups share an x in a panel, as for a ribbon without a color= mapping (one group), which therefore starts as ribbons under :auto; the tooltip then leaves the score out.

  • threshold: the share intervals=:auto compared score against; nothing when intervals=true/false fixes the start.

start, score and threshold are nothing when the switch is not offered.

AlgebraOfVega.geoshape Function
julia
geoshape(geometry; key=nothing, projection=automatic)

Join mapped table values to GeoJSON geometry and draw geographic shapes. geometry accepts a GeoJSON URL, a FeatureCollection dictionary, or a vector of Feature dictionaries. key is a shared column/property name or a data_column => geo_property pair; when omitted, the positional mapping supplies the shared name. Unmatched rows and features are not drawn. Use the color mapping for a numeric or categorical attribute and projection for the geographic projection. All layers in a map share one projection; the default is Mercator when no layer specifies another. Added point and line layers map longitude and latitude in degrees. Regions larger than half the globe are not supported.

This is a browser/Vega-Lite analysis. vsave can export it; the Makie sdraw path does not implement it. Use visual(; fill=nothing, stroke=:ink) when only a theme-aware boundary should be drawn.

AlgebraOfVega.geobox Function
julia
geobox(boxes; key=nothing, projection=automatic)

Draw each table row as the longitude/latitude box its key names, a map's grid cell. boxes is a table with the key column and one box per key in the columns west, south, east and north (degrees): any Tables.jl table, by_url(table, url) for a table the browser loads from an address, or the URL of such a table as JSON rows (rows_json(table)). key is the column both tables share, or a data_column => box_column pair; when omitted, the positional mapping supplies it. Rows whose key has no box, and boxes no row names, are not drawn.

It takes what geoshape takes: color and strokecolor mappings, col, row and layout facets, fixed visual(...) attributes, projection, and other layers on the map. Each box is drawn as one rectangle between its projected south-west and north-east corners, which is exact for projections that keep longitude and latitude lines straight and at right angles, such as the default Mercator. Through a projection that bends them, such as :albers, the rectangle between those two corners only approximates the box; draw such cells as polygons with geoshape.

This is a browser/Vega-Lite analysis. vsave can export it; the Makie sdraw path does not implement it.
